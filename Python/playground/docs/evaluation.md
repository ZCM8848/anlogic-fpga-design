## 3. 已发现的问题

1. **静态划痕误检（2026-10-28 已修 A）**：
   clip1 f399–f480 的 OSD 框来自中央 3D 打印划痕。复现：track #2 中心
   (623, 241)，81 帧总位移 <5 px，`vx` −7…+8。现在加入运动门控：
   `moved≥0.2D`、最近 5 帧 `window_move≤−0.5D`、`vx≤−4` 才显示/计数；
   复测 f380–f480 划痕区域 **0 个 visible 帧**，总计数仍为 13/4。
2. **碎片分裂**：背景差分把同一个球的亮条、暗体、拖影边缘切成多块。
   目前用 0.8D 面积加权合并；clip1 f240 从 3 块合并为 2 个球，目视正确。
3. **近距离/边缘球**：球在画面边缘时框被裁剪；计数用球心，不受框裁剪影响。
4. **密集簇 ID**：贪心最近邻在 7 球密集时可能交换 ID；计数只依赖过线事件。
5. **clip3 事件**：D=171 后为 3 次过线（f472/f536/f543），之前的 `cx=143`
   远跳消失；仍需标注/真值确认。
6. **clip2**：背景全白，明确排除。

## 4. 下一步（P2）

1. 用 Web 标注 **30–50 帧/段**，优先“密集帧”按钮给出的帧；标整条拖影。
2. 计算：
   - 检测：每帧球心匹配率（容差 0.5D）、误检/漏检；
   - 跟踪：ID 保持（人工 ID）或至少连续性；
   - 计数：与隐藏真值的总差值、差在哪个事件。
3. 调参优先级：
   - `merge_distance_ratio`（密集合并/分裂）
   - `track_gate_px`、`track_max_miss`、确认帧数
   - `bg_thr`、`min_area/max_area`
4. 若合并仍不可靠，启用算法文档里的备选：
   - 列高剖面拆分（每个 blob 存 ≤320 列 y 范围，帧尾找谷）
   - 已知半径竖直 Hough（只用于门线窄带）
5. 把最终参数固化到 `configs/`，并更新 `docs/fpga_mapping.md` 的资源表。
