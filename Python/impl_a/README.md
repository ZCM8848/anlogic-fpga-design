# 钢珠跟踪与计数系统（传统 CV / OpenCV 原型）

> 面向“全国大学生嵌入式芯片与系统设计竞赛'2026 · FPGA 赛道 · 选题二（基于安路 PH1P35 的实时数字图像处理系统）”的**算法验证原型**。
> 目标：用 **笔记本摄像头 + Python**，以**不依赖任何 AI/深度学习（不用 YOLO 等）的传统 CV 算法**，实现钢珠从滚入视野到滚出视野的**跟踪 + 计数**，并在画面 OSD 上叠加方框、ID 与计数值；同时尽量降低对外界环境光的要求。
> 本原型验证通过后，同一套数据流可直接按 `README` 末尾的“FPGA 移植对照”搬进 PH1P35。

---

## 1. 实现效果

- **全过程跟踪**：任一钢珠从进入视野到离开视野始终保持**同一个 ID、同一个框**（遮挡/摩接时用预测补位保持 ID）。
- **OSD 标注**：每颗钢珠画方框，并在**方框右上角标注 ID**；左上角显示 `Count: N`；叠加计数线与方向箭头；右下角预留“AL / Anlogic”标识位。
- **计数**：单方向虚拟计数线，确认轨迹按期望方向越线时 `+1`，每条轨迹去重，不重复计数。
- **抗环境光**：光照归一化 + 背景模型自适应 + 多线索时序确认（详见第 6 节）。
- **抗干扰**：尺度上限剔除人手等大物体；**颜色门**剔除高饱和的彩色物体/手指（金属钢珠是低饱和银灰色）。

处理流水线：

```
采集(1280x720@60 MJPG)
  → 下采样到 640x360
  → ROI 掩膜（只留轨道带）
  → 灰度 + 光照归一化(gray/大核模糊) [+可选 CLAHE]
  → 前景 = MOG2(在“光照归一化图”上建模, 抗全局亮度/曝光变化) [+可选帧差]
  → 形态学开/闭 → 竖向开运算去水平细条
  → 连通域 + 面积/圆度/填充率/长宽比筛选（剔除人手等大物体与细长伪影）
  → 颜色门：剔除非金属(高饱和, 如手指/彩色物体)
  → 质心 + 半径
  → 多目标跟踪（匀速预测 + 门限最近邻匹配 + 遮挡补位 + 方向约束）
  → 单向计数线计数
  → OSD 叠加 → 显示 / 录制
```

## 3. 快速开始（无需摄像头，先跑通）

```powershell
# 1) 生成一段合成测试视频（含钢珠、人手大块、缓慢光照变化）
python simulate.py --out sim_test.mp4 --seconds 20

# 2) 无窗口跑一遍，输出结果视频并打印最终计数
python main.py --video sim_test.mp4 --no-display --output out.mp4
# 正常情况会打印形如:  [result] frames=600  count=8  tracks_total=8

# 3) 带窗口观察 + 调参
python main.py --video sim_test.mp4
```

**在合成视频上的实测结果（本机验证）**：600 帧、1280×720 输入，处理分辨率 640×360；
真值“越过中线”的钢珠 10 颗，系统计数 **9**（≈90%）；人手大块被正确忽略。
可用 `main.py --video sim_test.mp4 --no-display --output out.mp4` 一键复现。

**在真实桌面视频上的实测结果**：钢珠（银色，直径约 80px）沿桌沿滚动时能被稳定框住并给同一 ID；
推球的**手指**被颜色门正确忽略（不再产生误框）；背景木纹噪声被压制（轨迹数从最初的数千条降到 ~12~22 条）。
**多球场景**（同一条轨道上 2~3 颗球同时滚）也能同时框出并各自标注 ID（如某帧 3 颗球同时框出）。
真实场景请务必用 `--calibrate` 框好 ROI 并测量钢珠直径后再演示。

**合规性**：测试素材分辨率为 1280×720（= 赛题基准分辨率，16:9），合规；但素材帧率为 30fps，
赛题演示基准是 60fps，正式验证建议用真机按 720p60(MJPG) 录制（`main.py --camera 1 --output reco.mp4`）。

**多段真实素材实测（本机验证）**：

| 素材 | 分辨率/帧率 | 场景 | 结果 |
|---|---|---|---|
| 钢珠.mp4 | 1280×720@30 | 单球沿桌沿滚（有手指入镜）| motion: count=6，手指被忽略 |
| 钢珠2.mp4 | 1280×720@30 | 2~3 球同轨道 | motion: count=9，多球同时框出 |
| 钢珠3.mp4 | 1280×720@30 | 3 球斜向快滚 | `--ball-diam 120`: count=4 |
| 钢珠4.mp4 | **1280×720@60** | 相机平移 + 多批球（真值 10）| motion: 2；**`--detector hough --count-mode exit`: count=10 ✅** |
| 钢珠5.mp4 | **1280×720@60** | 深色球浅背景、分批、相机移动（真值 10）| motion: 1；**`--detector hough --count-mode exit`: count=10 ✅** |

## 5. 现场标定（关键步骤）

摄像头位置固定后，先标定一次，结果自动存进 `config.json`：

```powershell
python main.py --calibrate          # 摄像头
python main.py --video sim_test.mp4 --calibrate   # 或视频
```

在标定窗口里：

| 按键 | 作用 |
|---|---|
| `1` | 拖拽矩形 = 设定 **ROI**（钢珠滚动所在的轨道/横带）|
| `2` | 先后点两下 = 设定 **计数线**（两点确定直线）|
| `3` | 先后点两下 = 设定 **运动方向**（第一点指向第二点）|
| `4` | 拖拽矩形框住一颗清晰钢珠 = **自动测量钢珠直径** |
| `r` | 清除 ROI / 计数线 |
| `s` | 保存并退出 |
| `q`/`ESC` | 放弃退出 |

也可以运行中按 `c` 随时重新标定。

**建议**：先把 ROI 框在轨道带上，这样可以极大压制复杂背景与反光干扰；再设定计数线（垂直于运动方向）与方向；最后测一次钢珠直径（决定面积门限）。

## 6. 抗外界环境光的手段

| 手段 | 说明 |
|---|---|
| 光照归一化 | 灰度除以“大核模糊”估计的照度，消除光照不均与整体明暗漂移 |
| 背景建模(归一化输入) | MOG2 建在光照归一化图上，全局亮度/自动曝光变化不会把整片区域误判为前景 |
| 相对阈值 | 阈值针对归一化图 / 前景，而非绝对灰度 |
| 时序确认 | 需连续多帧命中且方向一致才确认，抑制反光/噪声误检 |
| 锁定曝光 | `config.lock_exposure=True` 关掉自动曝光，避免亮度“呼吸” |
| 帧差法(可选) | 只对“运动”响应、对整体明暗漂移不敏感；背景有纹理时建议关闭 |

可调开关：`config.json` 里的 `use_illum_norm / illum_sigma / use_frame_diff / use_mog2 / diff_threshold / var_threshold`。若现场光照很稳、噪点大，可调 `var_threshold`、`diff_threshold` 与形态学核大小。

## 7. 参数说明（config.json / config.py）

| 参数 | 默认 | 含义 |
|---|---|---|
| `proc_scale` | 0.5 | 处理分辨率相对显示的比例（0.5 → 640x360） |
| `roi` | null | 检测区域 `[x,y,w,h]`（全分辨率坐标），null=全画面 |
| `line` | null | 计数线 `[[x1,y1],[x2,y2]]`，null=过中心自动线 |
| `direction` | [1,0] | 期望运动方向（单位向量） |
| `ball_diam_px` | 80 | 钢珠直径（全分辨率像素），用标定 `4` 测量（换机位要重测） |
| `area_tol` | 0.6 | 面积容差 ±60% |
| `min_circularity` | 0.35 | 圆度门限（4πA/P²），运动模糊时放宽 |
| `min_fill` | 0.45 | 外接矩形填充率门限 |
| `use_color_gate` | true | 颜色门开关（剔除彩色/高饱和物体） |
| `max_sat` | 90 | HSV 饱和度上限（0-255），超过判为非金属 |
| `use_mog2` | true | 背景建模开关（建在光照归一化图上，抗全局亮度变化） |
| `use_frame_diff` | false | 帧差法开关（有纹理背景时噪声大，默认关） |
| `var_threshold` | 26 | MOG2 方差阈值（越小越敏感、噪声越大） |
| `morph_open`/`morph_close` | 5 / 9 | 形态学开/闭核大小 |
| `destreak` | true | 竖向开运算去水平细条（高对比边界伪影） |
| `max_aspect` | 2.5 | 长宽比上限，剔除细长条带 |
| `max_gate` | 2.5 | 关联门限 = 该值 × 半径 |
| `min_hits` | 3 | 连续命中多少帧确认目标 |
| `max_coast` | 8 | 丢失后最多预测补位帧数（保持 ID） |
| `use_direction_filter` | true | 单方向约束，剔除反向运动干扰 |
| `detector_mode` | motion | 检测模式：motion / hough |
| `count_mode` | line | 计数模式：line / exit |
| `hough_min_radius`/`hough_max_radius` | 20 / 36 | 霍夫圆半径范围（处理分辨率坐标）|
| `hough_param2` | 24 | 霍夫圆累加器阈值（越小越敏感/误检越多）|
| `hough_dark_offset` | 20 | 暗块阈值 = 128 − offset |
| `hough_dark_mean` | 122 | 圆内平均灰度上限（须比背景暗）|
| `hough_dark_frac` | 0.55 | 圆内暗像素占比下限 |

## 9. 命令行参数

```
--camera N       指定摄像头序号
--video FILE     离线视频文件输入
--output FILE    保存带 OSD 的结果视频
--no-display     不弹窗（自动测试/无显示环境）
--calibrate      启动即进入标定
--config PATH    指定配置文件路径
--detector MODE  检测模式: motion(默认) / hough(霍夫圆,深色球+浅背景+相机平移)
--count-mode MODE 计数模式: line(默认,计数线) / exit(按轨迹离开视野计数)
--ball-diam PX   临时覆盖钢珠直径(全分辨率像素)
--area-tol T     临时覆盖面积容差
--max-frames N   处理 N 帧后退出(自动测试用)
--unlock-exposure 关闭手动曝光(自动曝光)
```

**两种检测模式怎么选：**

| 模式 | 原理 | 适用 |
|---|---|---|
| `motion`（默认）| MOG2 + 归一化/形态学/颜色门 | 背景静止、球与背景对比一般（如钢珠沿轨道滚）|
| `hough` | 光照归一化 + 霍夫圆 + “圆内须为暗块”校验 | **深色球在浅色背景、相机可能平移、球快或相互接触** |

**两种计数模式：**

| 模式 | 原理 | 适用 |
|---|---|---|
| `line`（默认）| 单向计数线穿越 | 相机固定、单向滚过 |
| `exit` | 已确认轨迹离开视野即计数 | **相机平移、方向不固定时更稳** |

## 10. FPGA 移植对照（PH1P35）

| 本原型模块 | 硬件实现建议 |
|---|---|
| 下采样 / 灰度 | 行缓存 + 定点灰度 `Y≈(77R+150G+29B)>>8` |
| 光照归一化 | 降采样背景缓存 + 双线性插值近似大核均值；除法用倒数 LUT |
| 背景建模(MOG2) | 用 **IIR 滑动均值** `bg=bg*(1-α)+cur*α`，`absdiff` 后阈值 |
| 帧差 | 行缓存保存 N-2 帧所需行（或整帧缓存）后做差分比较 |
| 阈值/形态学 | 3x3 窗口结构元 + 比较器/与或逻辑 |
| 连通域 + 面积/周长/包围盒 | 行 run-length 标记 + 并查集合并，边扫描边统计 |
| 圆度/填充率 | 定点乘除与比较（用面积、包围盒即可近似） |
| 跟踪（预测/匹配） | 每条轨迹一组寄存器(id,x,y,vx,vy,r,hits,miss)；距离平方比较 + 小规模并行仲裁 |
| 计数线穿越 | 直线方程 `a*x+b*y+c` 符号变化 = 一位触发器；方向校验用乘加比较 |
| OSD 叠加 | HDMI 输出侧图形发生器：方框用计数器生成波门，ID 用字模 ROM，Logo 用位图 ROM |

> 设计取舍：本原型的 **MOG2 / 大核高斯 / CLAHE** 在 FPGA 上资源开销较大或不易实现，已在上表给出**硬件友好替代方案**（IIR 背景、降采样背景缓存、跳过 CLAHE）。移植时建议以“**帧差 + IIR 背景 + ROI + 形状筛选 + 计数线**”为主线。

## 11. 调参建议 / 常见问题

- **一片乱框 / 噪声多**：调大 `var_threshold`、`diff_threshold`，增大 `morph_open`，提高 `min_circularity`，并务必画好 ROI。
- **漏检（框不稳）**：调小 `var_threshold`、`diff_threshold`，放宽 `area_tol`，降低 `min_fill`；确认 `ball_diam_px` 与实测一致。
- **ID 频繁跳变**：增大 `max_coast`、`max_gate`，提高 `min_hits`。
- **重复计数**：确认计数线垂直于运动方向、`direction` 设置正确；`min_hits` 可适当增大。
- **人数/人手也被框住**：说明尺度上限太松，用标定 `4` 重测直径，或调小 `area_tol`。
- **画面太暗/太亮**：调 `exposure`（锁定曝光时）或关闭 `lock_exposure` 让自动曝光工作。
