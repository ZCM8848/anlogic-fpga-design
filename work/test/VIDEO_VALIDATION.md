## 管线（与最新 bit 一致）

```
块域(16x16)暗块：DARK_THR=100 + 与 5 帧前的同块背景比较(低 CB_DELTA=20)
  形状筛选：MIN_BLKN=14、MAX_BLKN=400、填充率≥40%、长短边比≥50%、
            剔除贴左/上边与贴角、块宽高≤16
  贴球对拆分：长/短边比≥150% 且面积≥24 块 -> 按 2 颗输出
  -> a-b 预测(ALPHA=0.5, BETA=0.1875) + 贪心最近邻(GATE=320) + 丢失>MISS_K=35 删轨
  -> 计数：绿框轨迹预测出画面且命中≥4、丢失≤10 -> +1（不做消亡补计）
```

## 本轮修复

1. **计数规则**：删除"轨迹消亡补计"，只保留绿框轨迹预测出画面时 +1
   （`cv_top.v` 的 `O_count`）；静态暗块不再产生计数。
2. **检测背景**：`cv_blkdet.v` 由"上一帧 10×6 大格均值"改为
   **5 帧前的 80×45 块均值**（5 槽 ×4096 的 ERAM，读旧值后再写当前帧）：
   静止暗块被抑制；快球/并排球离开旧位置后与背景不同，不再被吞掉。
3. **跟踪参数**：`BETA_Q=48`（0.1875）、`GATE=320`，覆盖快球的帧间位移。
4. **CCL 缺陷修复**：`ft_ra` 原来用上一块的标签读特征表，行首块继承上行标签时
   会把面积清掉；改为"T_READ 寄存本块标签 → T_WR 读特征 → T_UPD 写回"三段，
   面积按整块累加（`tools/sim/tb_cv_blkdet.v` 验证：81 块矩形一次检出）。
5. **上下边缘计数门限**：左/右边缘出画面命中≥4；上/下边缘要求命中≥8。
   球的阴影/反光只形成 4 次命中的短轨迹，不再被计。
