## 内部二值视频流与调试视图

`cv_pipeline_sim.py --mask` 把 `cv_blkdet` 的 **80×45 块掩膜**（白 = 暗块，黑 = 背景）放大到
1280×720（每块 16×16 像素），用 FFV1 无损编码写成 `.mkv`，像素只有 0/255：

```bash
python work/camera_hdmi_720p/tools/sim/cv_pipeline_sim.py 钢珠9.mp4 钢珠9_二值识别.mkv 320 35 100 --mask
python work/camera_hdmi_720p/tools/sim/cv_pipeline_sim.py 钢珠10.mp4 钢珠10_二值识别.mkv 320 35 160 --mask
```

`--mask-osd` 在同样的块掩膜上叠加红框和白色 5×7 ID，对应 K2 状态 2 的调试画面：

```bash
python work/camera_hdmi_720p/tools/sim/cv_pipeline_sim.py 钢珠12.mp4 钢珠12_二值识别_叠加.mkv 320 35 160 --mask-osd
```

- 结果（桌面）：`钢珠9_二值识别.mkv` … `钢珠14_二值识别.mkv`，计数与 `_计数结果.mp4` 相同；
  `_二值识别_叠加.mkv` 是带框/ID 的调试视图。
- `--mask` 是检测器（`cv_blkdet`）交给 CCL 的输入掩膜，不含红框/ID；`--mask-osd` 是掩膜 + 跟踪框。
- 上板 K2 状态 2 用 `cv_blkdet.o_mask_bit`：在每块最后一个像素预读下一块的 `blk_mask`，得到上一帧的
  块掩膜，锁存后覆盖整块 16 个像素；与同样来自上一帧的跟踪框位置一致。块 0 在 `vs_rise` 预读。
- 离线 `--mask` / `--mask-osd` 用的是当前帧掩膜和当前帧框，与上板视图相差 1 帧，不影响计数核对。

## 历史修复记录（旧版检测器）

1. **计数规则**：删除"轨迹消亡补计"，只保留红框轨迹预测出画面时 +1
   （`cv_top.v` 的 `O_count`）；静态暗块不再产生计数。
2. **检测背景**：`cv_blkdet.v` 由"上一帧 10×6 大格均值"改为
   **5 帧前的 80×45 块均值**（5 槽 ×4096 的 ERAM，读旧值后再写当前帧）：
   静止暗块被抑制；快球/并排球离开旧位置后与背景不同，不再被吞掉。
3. **跟踪参数**：`BETA_Q=48`（0.1875）、`GATE=320`，覆盖快球的帧间位移。
4. **CCL 缺陷修复**：`ft_ra` 原来用上一块的标签读特征表，行首块继承上行标签时
   会把面积清掉；改为"T_READ 寄存本块标签 → T_WR 读特征 → T_UPD 写回"三段，
   面积按整块累加（`tools/sim/tb_cv_blkdet.v` 验证：81 块矩形一次检出）。
5. **上下边缘计数门限**：左/右边缘出画面命中≥4；上/下边缘要求命中≥6。
   球的阴影/反光只形成 4 次命中的短轨迹，不再被计；顶边真实离场（6 次）保留。
6. **亮场景宽团块**：`DARK_THR≥130` 时块宽/高上限 16→32、填充率 40%→35%，
   覆盖快球+运动模糊；贴球对拆分在该模式下要求填充率≥60%，避免拆散单球拖影。
7. **亮场景左侧入场**：允许贴左边、宽高≥6、填充≥50% 的紧凑团块（第一颗球从左侧入场）。
8. **角部重复计数抑制**：顶/底 100px 内、3 帧内、距离≤150px 的两次离场只计一次；
   左右边缘命中门限：窄场景 3、亮场景 2。
9. **底部左侧反光带**：`y>650` 且 `x<700` 的离场要求命中≥8，滤掉阴影/倒影。
10. **亮场景并排拆分**：宽/高≥20 块且面积≥100 的团块按 2 颗拆分（并排双球）。
11. **短轨迹抑制**：命中≤3 的轨迹若在 2 帧/80px 内紧邻已计离场，或在 15 帧/300px 内
    靠近已计离场且从底边（y>550）离开，视为碎片/阴影，不再计数。
