# 钢珠检测/跟踪/计数 —— 离线录像验证记录

> 没有摄像头时，用**与 RTL 同参的等价管线**对桌面的实拍录像做验证。
> 脚本：`work/camera_hdmi_720p/tools/sim/cv_pipeline_sim.py`（检测=`cv_blkdet`，
> 跟踪=`cv_top` 的 a-b+贪心 NN，计数=`O_count` 的"出画面即计 + 消亡补计"）。

## 管线（与最新 bit 一致）

```
块域(16x16)暗块：DARK_THR=100 + 局部对比(比上一帧大格背景低 CB_DELTA=20)
  形状筛选：MIN_BLKN=14、MAX_BLKN=400、填充率≥40%、长短边比≥50%、
            剔除贴左/上边与贴角、块宽高≤16
  贴球对拆分：长/短边比≥150% 且面积≥24 块 -> 按 2 颗输出
  -> a-b 预测(ALPHA=0.5, BETA=0.0625) + 贪心最近邻(GATE=240) + 丢失>MISS_K=35 删轨
  -> 计数：预测出画面且命中≥4、丢失≤10 -> 即时 +1；
          未出画面的轨迹消亡时命中≥5 -> 补计一次(去重)
```

## 钢珠9 明细

| 项目 | 内容 |
|---|---|
| bit | `work/test/M7_view/camera_hdmi_720p.bit`，md5 `CF7C91E885BB233FB760A8F920B73D24` |
| 计数时刻 | 183 · 255 · 432 · 447 · 514 · 550 · 550 · 646 · 867 · 929 |

- **真值**（按帧差运动段逐颗数）：f96–112 ×1、f237–256 ×2、f419–447 ×4、
  f634–645 ×1、f855–868 ×1、f915–930 ×1 → **10 颗**。
- **10 次计数里只有 6 次是真实球离开画面**（255/432/447/646/867/929）。
- **4 次为静态暗块的消亡补计**：183/514 是画面底部两个暗块，550/550 是右上角两个暗块。
- **漏计 4 颗真实球**：f96–112 的 1 颗、f249–256 的 1 颗、f419–447 的 2 颗
  （快球或并排双球超出块域门限，或未与已有轨迹配上）。
- **结论**：总数 10 是漏计与误计相互抵消的结果；画面底部/右上会挂出静态绿框，
  快速段有球无框。

## 复现

```bash
python work/camera_hdmi_720p/tools/sim/cv_pipeline_sim.py 钢珠9.mp4 钢珠9_计数结果.mp4 240 35 100 1
python work/camera_hdmi_720p/tools/sim/cv_pipeline_sim.py 钢珠8.mp4 out8.mp4 240 35 100 1
```

- 参数缺省值取当前 bit：`GATE=240`、`MISS_K=35`、`DARK=100`；
  位置参数 `MIN_HITS` 为旧接口，保留兼容、已不参与计数。
- `DARK_THR` 场景相关（早期测试中钢珠4 用 140）；上板可用 **K3/K4** 调偏置
  （`DARK_THR=100` 基础 + 偏置，范围 0..2047），串口看 `C=`（累计）与 `NB=`（当前帧）。
