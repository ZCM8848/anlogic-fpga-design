## 现象
- 屏幕整体近黑（均匀灰 + 环境光左右渐变）；左上角一根 **64×8 白色横线**。

## 判读（全链条已定位）
1. 白线 = **W2 显示侧标记**（设计坐标 x 0..64、y 200..207）——实测照片坐标 x 40..224、
   y 622..651，比例尺 s=2.875 反解 = x 0..64、y 200..210 ✓ 逐像素吻合。
2. 屏幕其余全黑 = **设计行为**：`fb_rd.v:229` 的「无帧时输出黑」门（S_vd_s[1] = 同步后的
   `I_rd_valid_f`；fb_ctrl 无 READY 帧 → O_rd_valid=0）。W2 白条在门外（S_mk1 直通白）。
3. W3（0x88 灰柱）缺席 = 同一原因：数据通路整体被「无帧」门挡住，而非回填引擎故障。
   W1/W4/W5 同理（打包/排空引擎无摄像头不运转）。
4. 照片中的均匀灰 + 渐变 = 黑屏 + 环境光反射（非内容）。

## 结论
- 横线 = **预期行为** ✓；顺带再次证实显示侧坐标诚实。
- **W5 定位实验必须接摄像头**：无帧时数据通路全黑，白带不会出现。
