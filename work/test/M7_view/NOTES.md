# M7_view — 上板"黑屏+绿框"修复（MASK_VIEW）

> 现象：烧板后显示器上**只有绿框、其余全黑**。

## 根因：显示模式配错，不是相机坏

`cv_top.v:517`
```verilog
wire [23:0] cv_base = (MASK_VIEW!=0) ? (w_mask ? 24'hFFFFFF : 24'h000000) : I_data;
```
`design_top_wrapper.v` 传的是 **`MASK_VIEW=1`** → 输出的是**二值掩膜视图**（暗块=白、其余=黑），
**根本不是摄像头图像**。屏幕上于是只有掩膜 + CV 绿框/白字。

### 反证相机是好的
若相机无数据/全黑 → 像素 0 → `w_y=0 < DARK_THR` → 掩膜应**全白**。
实际是**全黑**（= 到处都亮）⇒ **相机给的是正常亮画面** ✅

## 改动
| 文件 | 改动 |
|---|---|
| `rtl/cv/cv_top.v` | `MASK_VIEW` 默认 `1→0` |
| `rtl/top/design_top_wrapper.v` | 例化参数 `.MASK_VIEW(1)→(0)` |

`MASK_VIEW=0` ⇒ `cv_base = I_data` ⇒ 输出**真实画面 + 绿框/ID**。
**CV 检测/跟踪/计数逻辑一行未改**（只改显示基准）。

## 上板验收
1. 烧 `td_project\camera_hdmi_720p.bit`；
2. **SW4=1**（摄像头）；**按 KEY2 开 CV**；
3. 预期：**实时画面 + 球上绿框 + 白色 ID 数字**；
4. 串口：`CAM ID=.. OK=.. CFG=.. DDR=.. CV=1 NB=.. TH=.. C=..`，`C=` 随球出画面累加；
5. K3/K4 调 `DARK_THR`（局部对比下不敏感）。

> 调试时若要看掩膜：把 `MASK_VIEW` 改回 1 重编即可（或后续接到按键上运行时切换）。
