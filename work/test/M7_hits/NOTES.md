# M7_hits — step1：剔除桌沿假块 + 确认门限计数

> 解决"没有钢珠却在计数"：假计数根因是**底部黑色桌沿**的碎块被当成球；本版剔除过宽/过高块，
> 并加"确认门限"（命中≥MIN_HITS 才计数）。

## 改动

- `cv_blkdet.f_pass`：增加 **`fn_wb<=16 && fn_hb<=16`** —— 球约 7 块宽，桌沿/长条几十块宽 → 剔除。
- `cv_top`：新增 `r_hits[0:MAX_BLOBS-1]`（每槽命中帧数，饱和）+ **`MIN_HITS=3`**；
  只有命中≥MIN_HITS 的轨迹才允许计数（"出画面即计/消亡补计"）。
