# M7_exitbg —— 只按绿框出画面计数 + 5 帧块背景 + CCL 行首缺陷修复

> 问题（`钢珠9_计数结果.mp4`，M7_view bit）：
> 1. 第一颗球没有计数（框也没有）；
> 2. 7–10 s 画面无球却自动 +1（底部/右上静态暗块的"消亡补计"）；
> 3. 快球与并排双球漏检，靠误计凑成总数 10。

## RTL 改动

| 文件 | 改动 |
|---|---|
| `rtl/cv/cv_top.v` | 删除"未出画面轨迹消亡补计"分支，只保留 `t_out` 即时计数；`BETA_Q=48`、`GATE=320`；删除 `MIN_HITS/MIN_HITS_DT` |
| `rtl/cv/cv_top.v` | 上下边缘出画面单独设 `MIN_HITS_V=6`（左右边缘仍为 4），滤掉球下方阴影/反光的 4 次命中小轨迹，保留顶边真实离场 |
| `rtl/cv/cv_blkdet.v` | 亮场景（`eff_thr≥130`）放宽块宽/高 16→32、填充率 40%→35%；允许左侧紧凑团块入场；宽/高≥20 且面积≥100 的团块按 2 颗拆分 |
| `rtl/cv/cv_top.v` | 角部重复计数抑制；左右边缘命中门限窄场景 3、亮场景 2；底部左侧反光带需命中≥8；短轨迹（命中≤3）在 2 帧/80px 或底边 15 帧/300px 内紧邻已计离场时不计数 |
| `rtl/cv/cv_blkdet.v` | 背景由"上一帧 10×6 大格"改为**5 帧前 80×45 块均值**（5 槽 ×4096 ERAM，读旧值后写当前帧）；`bg_blk` 在块内锁存，避开 BRAM 读延迟；比较用 9 位加法防 `+CB_DELTA` 溢出 |
| `rtl/cv/cv_blkdet.v` | CCL 特征读地址修复：行首块继承上行标签时，原 `ft_ra=t_lbl`（上一块标签）会读到别的标签、把面积清零；改为 T_READ 寄存本块标签 → T_WR 读特征 → T_UPD 写回（多 1 拍/块，扫描约 11k 周期） |
| `rtl/top/design_top_wrapper.v` | `BETA_Q=48`、`GATE=320`、`MIN_FILL=40`、`MIN_RATIO=50`；删除死亡补计参数 |

## K2 三态显示

| 状态 | 画面 | 检测 | 串口 |
|---|---|---|---|
| 0 | 纯摄像头（SW4=1） | 关，轨迹/计数清零 | `CV=0` |
| 1 | 真实画面 + 绿框 + 白色 ID | 开 | `CV=1` |
| 2 | 上一帧 80×45 块掩膜放大（白=暗块）+ 绿框 + 白色 ID | 开 | `CV=2` |

- K2 去抖后循环 0→1→2→0；K3/K4 阈值调节只在状态 1/2 有效。
- 状态 2 的掩膜来自 `cv_blkdet.o_mask_bit`：每块最后一个像素预读下一块 `blk_mask`（仍是上一帧值），
  `vs_rise` 预读块 0；锁存后覆盖整块 16 像素，与同样来自上一帧的跟踪框一致。
- 状态 0 时 `cv_top` 主状态机停在 `S_IDLE`，`cv_blkdet` 继续产生掩膜与检测表，保证下次进入状态 2
  时掩膜已就绪；`I_cv_on` 下降沿清 `track[]`、`det[]`、`hits` 和累计计数。

## 上板验收

1. 烧 `td_project\camera_hdmi_720p.bit` 或本目录的 bit；
2. **SW4=1**（摄像头）；按 **KEY2** 循环 `CV=0→1→2→0`；
3. 状态 1：真实图像 + 绿框；状态 2：块掩膜 + 绿框；球完全离开画面时才 +1；静止暗块不挂框、不计数；
4. 串口：状态 1/2 时 `CV=1/2 NB=.. TH=.. C=..`，`C=` 与画面计数一致；状态 0 时 `CV=0`；
5. K3/K4 仅在状态 1/2 调 `DARK_THR` 偏置；状态 0 时无效。
