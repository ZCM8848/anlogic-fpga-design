# M7_exitbg —— 只按绿框出画面计数 + 5 帧块背景 + CCL 行首缺陷修复

> 问题（`钢珠9_计数结果.mp4`，M7_view bit）：
> 1. 第一颗球没有计数（框也没有）；
> 2. 7–10 s 画面无球却自动 +1（底部/右上静态暗块的"消亡补计"）；
> 3. 快球与并排双球漏检，靠误计凑成总数 10。

## RTL 改动

| 文件 | 改动 |
|---|---|
| `rtl/cv/cv_top.v` | 删除"未出画面轨迹消亡补计"分支，只保留 `t_out` 即时计数；`BETA_Q=48`、`GATE=320`；删除 `MIN_HITS/MIN_HITS_DT` |
| `rtl/cv/cv_top.v` | 上下边缘出画面单独设 `MIN_HITS_V=8`（左右边缘仍为 4），滤掉球下方阴影/反光的 4 次命中小轨迹 |
| `rtl/cv/cv_blkdet.v` | 背景由"上一帧 10×6 大格"改为**5 帧前 80×45 块均值**（5 槽 ×4096 ERAM，读旧值后写当前帧）；`bg_blk` 在块内锁存，避开 BRAM 读延迟；比较用 9 位加法防 `+CB_DELTA` 溢出 |
| `rtl/cv/cv_blkdet.v` | CCL 特征读地址修复：行首块继承上行标签时，原 `ft_ra=t_lbl`（上一块标签）会读到别的标签、把面积清零；改为 T_READ 寄存本块标签 → T_WR 读特征 → T_UPD 写回（多 1 拍/块，扫描约 11k 周期） |
| `rtl/top/design_top_wrapper.v` | `BETA_Q=48`、`GATE=320`、`MIN_FILL=40`、`MIN_RATIO=50`；删除死亡补计参数 |

## 上板验收

1. 烧 `td_project\camera_hdmi_720p.bit` 或本目录的 bit；
2. **SW4=1**（摄像头）；按 **KEY2** 开 CV；
3. 画面：真实图像 + 绿框；球完全离开画面时才 +1；静止暗块不挂框、不计数；
4. 串口：`CV=1 NB=.. TH=.. C=..`，`C=` 与画面计数一致；
5. K3/K4 仍可调 `DARK_THR` 偏置。
