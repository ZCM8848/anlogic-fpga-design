# M7_track — 跟踪/计数问题修正版

> 修 钢珠4 "跟踪计数明显错误"：① 幻影框（滑行轨迹被画/被计）；② 检测稀疏（运动模糊被形状筛选拒）。

## 修的两处

### ① 幻影框（跟踪）
跟踪器把**没有检测、纯预测"滑行"**的轨迹也画出来并按"出画面"计数 → 边缘出现空框
（钢珠4 第 140 帧的重叠 ID2/ID4、第 220 帧的空框 ID6）。

**修**：`cv_top` 的**叠加**与**出画面计数**都只对 **`missed<=2`（最近有检测）**的轨迹生效；
纯滑行的轨迹不画、不按 exit 计。

### ② 检测稀疏（检测）
钢珠4 检出总数只有钢珠5 的 ~1/4（73 vs 260）。原因：钢珠4 **相机平移 + 球快滚 → 运动模糊把
球块拉长** → 被严格的长短比(≥50%)拒掉。

**修**：放宽形状筛选 `MIN_FILL/MIN_RATIO 40/50 → 30/30`（`design_top_wrapper`）→ 检出翻倍。

> 边缘剔除保持**只剔左/上边**（`cv_blkdet` 原有行为）——四边全剔会把"靠边滚过的球"也丢掉
> （钢珠4 计数因此掉到 5）。
