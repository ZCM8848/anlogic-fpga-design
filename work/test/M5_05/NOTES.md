# M5-05 诊断 v2 照片判读结论（2026-09-27）

照片：`1790493491064.jpg`（4096×3072 竖幅特写）、`1790493491151.jpg`（4096×3072 竖幅特写）、
`1790493491196.jpg`（**3409×1977 全屏视图，唯一可全屏标定的一张**）。

> 教训：判读前必须先核实分辨率/幅面。064/151 为竖幅特写（屏横轴在照片纵轴方向），
> 196 才是全屏横向视图；此前基于错误幅面的测量作废。

## 标定（以 196 为准）

- 锚点：W2 白条左边缘 = 屏幕 x0（设计 x=0）；屏幕左边缘照片列 ≈ 39.5。
- 比例尺：W2 白条（设计 64px）实测照片宽 ≈ 168.5px ⇒ s ≈ 2.63；理论屏宽 ≈ 3381px，照片右缘
  恰好截掉屏幕最右 ~9px（右边缘测量须用外侧内容列外推，勿用 >190 阈值短段）。

## 三个标记实测落点

| 标记 | 设计落点 | 实测（196，换算为屏幕坐标） | 结论 |
|------|----------|------------------------------|------|
| **W2** 白条（显示侧 `(I_x,I_y)`，x<64、200≤y<208） | x 0..64 | x ≈ 0..64，y ≈ 199..206（≈设计原位） | **显示读出坐标诚实** |
| **W3/W4** 灰柱（回填 got=0 → 0x88 / 排空 ptr=0 → 0x55） | 屏幕第 0 字 | x ≈ 1..15，0x88/0x55 **逐行交替** | **回填 got=0、排空 ptr=0 均诚实落位（第 0 字）** |
| **W1** 白框（打包侧坐标，`PROBE_OVL`） | 贴屏幕边缘 | **x ≈ 200..215**（两 8px 竖边并排：一侧在 200..207、另一侧在 208..215） | **打包第 m 字 → 屏幕第 m+13 字（mod 80 回绕特征），≈208px** |

## 补充测量

- 屏幕最右列（x≈1272..1279 对应照片列 3397..3409）实测 = 内容（亮度 43..102），**非白** ⇒
  排除「打包之前/输入相位偏移」类解释（若输入相位偏移，此处应出现帧边框白）。
- W1 两竖边在 200..215 并排且**左右顺序交错**（右框白段出现在左、左框白段在右）——
  这正是「+13 字 mod 80」穿越行尾的特征签名（79+13≡12、0+13=13）。

## 结论

**+13 字（≈208px）旋转位于「打包写入之后、显示读出之前」的中段**；
显示读出、回填索引、排空索引/地址三个环节已在照片上被逐一证伪为偏移源。
