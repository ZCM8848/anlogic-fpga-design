# M7_corner — 贴角假块剔除版

> 针对"没有钢珠却在计数"：假计数多来自**画面边角的假检出**。本轮在 `cv_blkdet` 增加**贴角剔除**。

## 改动

`cv_blkdet.f_pass` 增加 `fn_corner = (贴左|贴右) & (贴上|贴下)` → **同时贴两个边的块**剔除。
靠边滚过的球只贴**一个边**，不受影响（不像"四边全剔"会把靠边球也删掉，钢珠4 会掉到 5）。

## 诚实结论（钢珠4/5 的跟踪计数）

- **钢珠5**（球在画面中间、光照稳定）：跟踪计数基本正常（11 左右，偶有 1 个误差）。
- **钢珠4**（相机平移、球常贴边、运动模糊）**本简化检测器无法干净处理**：
  - 假计数：开头 13/41/44 来自**短命假轨迹**（假的短检出 → 预测出画面 → 计数）；贴角剔除没能去掉
    （这些块不正好在角上）。
  - 漏跟：部分帧检测不到球 → 该球没框。
  - 试过的补救（四边剔除 / 贴角剔除 / 局部对比 / hits 门限）都只能部分改善，且有代价
    （四边剔除把靠边球也删；hits 门限把漏检多的真球也删）。
- 要真正解决钢珠4，需要**更强的检测**（参考实现对钢珠4 用的是霍夫圆/暗块 + 更完整的跟踪），
  或引入**自适应/局部对比阈值**（RTL 成本较高）。
