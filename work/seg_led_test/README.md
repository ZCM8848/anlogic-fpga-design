# seg_led_test — 8 位数码管（BCD 管）测试

独立 TD 工程，用于验证 HX1P35A 板载 **8 位七段数码管** 的段选/位选、扫描显示、SW1 模式切换和 KEY1 消抖。

## 硬件确认（重要）

板手册《新HX1P35A开发板手册-HDL版2604》§11 明确写的是：

> “我们采用的数码管为 **2 组 4 位一体** 的八段数码管，共阳数码管……”

- 即 **2 × 4 = 8 位**，满足本次测试的 8 位要求，**没有触发“位数不符立即停止”的条件**。
- 实物排列是**单排 4+4**（两组 4 位模块并排，中间有间隔），不是两行四列；总位数仍是 8 位。
- 数码管与 8 组双色 LED 复用 16 根引脚，**板上 SW6 必须拨到“数码管”一侧（拨上）**，否则看到的是双色 LED。

> 极性说明：板手册正文写“SEL 高电平有效”，但原理图 §17 的 Q1~Q8 是 **PNP9012**（基极经 470R 接 SEL，发射极接 DIGVCC），
> 低电平才导通；厂商 `7_seg_led` 例程也用低有效位选。本工程按**低有效**实现。
> 若实测发现位选相反，把 `rtl/seg_led_test_top.v` 里的 `SEL_ACTIVE_LOW` 改成 `1'b0` 重新编译即可。

## 功能

| SW1（A4） | KEY1（D5） | 显示 |
|---|---|---|
| 0（拨下） | 无效 | 从左到右静态显示 `0 1 2 3 4 5 6 7` |
| 1（拨上） | 按一次 | 前进一步：`00000000 → 11111111 → 22222222 → … → 99999999 → 00000000 …` |
| 1（拨上） | 再按一次 | 再前进一步（不自动跑） |

- KEY1 做 **20 ms 消抖**，每次按下只前进一步，按住不会连续触发。
- SW1=0 时计数复位为 0，切回 SW1=1 后从 `00000000` 开始。
- 扫描：每位 1 ms，8 位整帧 8 ms（125 Hz），无可见闪烁。
- 段码：共阳，低电平点亮；`O_seg[7:0] = {DP,g,f,e,d,c,b,a}`。

### 位选 `O_sel[7:0]`（低有效）

| 位 | FPGA | 物理位置 |
|---|---|---|
| `O_sel[0]` | A14 | 最右位 |
| `O_sel[1]` | B15 | 右起第 2 位 |
| `O_sel[2]` | A15 | 右起第 3 位 |
| `O_sel[3]` | B16 | 右起第 4 位 |
| `O_sel[4]` | A18 | 右起第 5 位 |
| `O_sel[5]` | A17 | 右起第 6 位 |
| `O_sel[6]` | G14 | 右起第 7 位 |
| `O_sel[7]` | G15 | 最左位 |

> 板手册表格里的网络名 `SEL0` 是“左起第 1 位”（G15），而厂商例程的 RTL 端口 `SEL[0]` 是 A14（最右位）；
> 两者只是命名方向相反。本工程沿用厂商 RTL 端口顺序，所以静态显示时 `O_sel[7]` 显示 0、`O_sel[0]` 显示 7。

## 仿真自检

`tools/sim/tb_seg_led_test.v` 覆盖：

1. SW1=0 时 8 位从左到右为 `0..7`；
2. SW1=1 初始 `00000000`；
3. 按一次 K1 只前进一步到 `11111111`；
4. 再按一次到 `22222222`；连续按到 `99999999` 后再按回到 `00000000`；
5. 快速抖动不会误触发；
6. 切回 SW1=0 恢复静态图形。

运行：

```powershell
powershell -File tools/sim/run.ps1
```

或手动：

```powershell
$env:PATH = "D:\iverilog\bin;D:\iverilog\lib;" + $env:PATH
iverilog -g2005 -o build.vvp rtl/seg_led_test_top.v tools/sim/tb_seg_led_test.v
vvp build.vvp
```

当前结果：**PASS**（静态图形 / 计数 / 消抖 / SW1 复位全部通过）。

## 上板检查清单

1. SW6 拨到数码管一侧（拨上）。
2. 烧录最新 `seg_led_test.bit`，确认 LED/电源正常。
3. SW1=0：显示 `01234567`（左→右）。若顺序相反，说明位选物理方向与厂商 RTL 端口命名相反，按上面 `O_sel` 表调整映射。
4. SW1=1：显示 `00000000`；每按一次 K1 前进一步：`11111111`、`22222222`……到 `99999999` 后回到 `00000000`。按住 K1 不会连续跳变。
5. 若个位数码管不亮/段码错位，先核对 SW6、排线/器件，再检查 `O_seg` 段码表。
