**源视频**：`C:\Users\Z___C\Downloads\VID_20261027_013309.mp4`
**分析脚本**：`test\led_blink_analysis.py`
**结果目录**：`test\results\`

> 原始文件是 1920×1080 + 旋转 -90° 的竖屏视频。分析前先转成物理竖屏的
> `test\VID_20261027_013309_rotated.mp4`（1080×1920，保留原时间戳），
> 结果里的坐标/时间都对应这个竖屏版本；`player\port_video.mp4` 也是它。

## 视频 / 分析方法

- 1080 × 1920 @ 60 fps，共 2500 帧，时长 41.33 s；近距离固定拍摄，摄像头缓慢移动。
- 橙色灯在网口上方，亮度很高，过曝后灯芯接近白色。检测时先用橙色掩膜找到 LED 的橙色外壳，再在外壳包围盒内取最亮点（灯芯）作为跟踪位置；在灯芯处取 7×7 窗口的最大红色分量作为亮度。
- 亮度分布：OFF 时 R 约 80–170，ON 时 R = 255（过渡帧约 210–225）；Otsu 阈值 **R = 189**。
- 绿色链路灯从视频开头就亮，且端口全程在画面内，所以有效观测窗为 **0 – 41.333 s**。
- 逐帧状态转换成 ON/OFF 区间；跳变发生在两帧之间，报告值取两帧时间的中点，**时间分辨率 ±1 帧 ≈ ±8 ms**。

## 关键结果

| 项目 | 结果 |
|---|---|
| 有效观测窗 | 0.000 – 41.333 s（41.33 s，全部帧） |
| 橙色灯状态 | ON 占 **67.5 %**，OFF 占 32.5 % |
| OFF 脉冲（肉眼看到的“闪一下”） | **154 次** |
| 单次 OFF 时长 | 17 – 133 ms，中位 **117 ms**（7 帧 ≈ 116.7 ms） |
| 相邻 OFF 起始间隔 | 33 – 833 ms，中位 **250 ms** |
| 主导节律 | **约 4 Hz 的规律闪烁**：周期 ≈ 250 ms（ON ≈ 133 ms + OFF ≈ 117 ms） |
| 停顿 | 空闲段会暂停闪烁、保持常亮约 0.5–0.8 s，因此整体 ON 占比高于 50 % |

> **这份数据直接定位了一个关键 bug（2026-10-27）**：
> 固件里帧间隔被设为 **25,000,000 个时钟周期**。实测闪烁周期 **250 ms**
> ⇒ 实际时钟 = 25,000,000 / 0.250 s = **100 MHz**，而不是设计目标 125 MHz。
> Anlogic PLL 的频率公式是 `C0 = (FIN/REFCLK_DIV) × FBCLK_DIV`，
> 只改 `CLKC0_DIV` 不改变输出频率。改成 `REFCLK_DIV=2, FBCLK_DIV=5` 后
> 周期变为 200 ms、抓包帧内容完全正确。详见 `docs/hardware/HW_ETH_RGMII.md`。

与前两段“偶发短促熄灭”的视频不同，这一段的橙色灯是**连续规律闪烁**：在 0–41 s 内绝大多数时间以约 250 ms 的周期亮/灭（亮 133 ms、灭 117 ms），中间夹杂若干段 0.5–0.8 s 的常亮停顿。

## 文件说明

| 文件 | 内容 |
|---|---|
| `frames.csv` | 每一帧：时间、`visible`、ON/OFF、灯芯亮度、橙色外壳面积、灯芯坐标 |
| `events.csv` | 所有 ON/OFF 区间 |
| `off_pulses.csv` | 154 次 OFF 脉冲，含起止、时长、与上一次的间隔 |
| `summary.txt` | 纯文本统计摘要 |
| `led_timeline.png` | 全片亮度波形 + ON/OFF 状态 |
| `led_timeline_zoom.png` | 分 4 段放大的波形 |
| `led_brightness_hist.png` | 亮度直方图与阈值 |
| `verification.jpg` | 等间隔抽帧检查图，橙色灯位置用黄圈标出 |
| `led_on_off_zoom.png` | 同一机位下 ON / OFF 两帧的放大对比 |
| `led_tracked.mp4` | 带状态标注与黄圈的验证视频 |

## 交互式核对页面

`test\player\index.html`（双击即可打开，视频已一起复制到同目录）

- 左边：原视频（竖屏），黄圈标出跟踪到的橙色灯；下方是约 2.5× 放大窗口
- 右边：由 `frames.csv` 驱动的实时读数（当前 ON/OFF、本段持续时间、距下次变化、熄灭计数）
- 全程时序条 + 局部放大波形（2 / 6 / 12 s 窗口），点击任意位置可跳转
- 154 次熄灭表格：点击任意行会跳到该次熄灭前 0.4 s 并以 0.5× 播放；可勾选“循环该段”
- 快捷键：空格播放/暂停，←/→ 单帧步进

页面由 `python test\make_timing_player.py` 生成，数据已经内嵌，不需要服务器。
