# HW_SC520CS — SC520CS MIPI 摄像头参数（以 `work/` 已验证实现为准）

> 传感器：**SmartSens（思特威）SC520CS**，500 万像素 CMOS 图像传感器，MIPI 输出。
> **权威来源**：本项目 `work/camera_hdmi_720p` 中**已上板验证**的 RTL 与配置：
> - `rtl/camera/uics520reg_720p60.v`（165 条初始化寄存器表）
> - `rtl/camera/uicfgcs520.v`（上电时序 / I²C 流程 / ID 校验）
> - `constraints/pin.adc`（控制引脚）
> - `docs/TECHNICAL_DETAILS.md`（整链路）
>
> 背景/上限参数引自 SC520CS 数据手册 V1.6（SC520DS）与设计应用指南 V1.4（SC520APP）。
> **若数据手册与本项目 RTL 不一致，一律以 RTL 为准。**

## 1. 本项目实际工作模式（已验证）

来源：`uics520reg_720p60.v` 表头注释 + 上板验收记录（`docs/TECHNICAL_DETAILS.md`、M2/M3/M6）。

| 参数 | 值 |
|---|---|
| 输出分辨率 | **1280 × 720 @ 60 fps（HD 模式）** |
| MCLK（EXTCLK） | **24 MHz**（FPGA 侧实供 **23.809524 MHz**，见 §5） |
| MIPI | **2-lane**，**RAW10**，Lane 速率 **828 Mbps** |
| 传感器内部处理 | 启用 **VBIN（垂直 binning）+ HSUB（水平 sub）**，直接输出真实 720p |
| I²C 从机地址 | **7-bit 0x36**（8-bit 写 0x6c / 读 0x6d） |
| 初始化寄存器数 | **165 条** |
| Free-run | 寄存器 `0x3222 = 0x00`（**关闭 Slave 模式**，自由运行） |
| 数据长包 DT | **0x2b**（RAW10）；帧/行同步短包 DT 见 §6 |
| 每行字节数（WC） | **1600 字节**（= 1280 px × 10 bit / 8），实测包头 `2B 06 40` |

> 实测链路（M3 验收）：`MIPI HS=1 L=0720 W=01280 G=0320 ER=00`，帧率 ≈ 59.6~60 fps。

## 4. I²C 配置接口

来源：SC520DS §1.4、SC520APP §4，与 `uicfgcs520.v` 一致。

| SID 电平 | 7-bit 设备地址 | 8-bit 写地址 | 8-bit 读地址 |
|---|---|---|---|
| 低（默认） | **7'h36** | **8'h6c** | 8'h6d |
| 高 | 7'h10 | 8'h20 | 8'h21 |

- 消息格式：**16-bit 子地址 + 8-bit 数据 + 7-bit 设备地址**。
- 速度：Standard-mode ≤ 100 kHz / Fast-mode ≤ 400 kHz。本项目 I²C 主机约 **100 kHz**。
- RTL 事实（`uicfgcs520.v`）：`CAM_ID = 8'h6c`；上电后先按 `0x3107/0x3108` 读 **Sensor ID**。

### Sensor ID（SC520DS 表 1-5）

| 寄存器 | 默认 | 说明 |
|---|---|---|
| 0x3107 | 0xee | ID[15:8] |
| 0x3108 | 0x4b | ID[7:0] |

- **加载初始化 setting 前**读到 `0xEE4B`；**加载后**读到 `0x9E4B`。
- `uicfgcs520.v` 的判据：读到 `0xEE4B` 或 `0x9E4B` 均视为成功（`O_sensor_id_ok=1`）。

## 5. 上电时序与 MCLK

来源：SC520DS §1.3、SC520APP §1.2；本项目 `uicfgcs520.v`。

- 电源无先后顺序要求（AVDD/DVDD/DOVDD）。
- 上电关键延时：**T4（XSHUTDN 高位相对上电）≥ 1 ms**，**T5 ≥ 5 ms**。
- 本项目实现：复位释放后 **PWDNB 拉低 2 ms**（≥T4），再拉高并等 **8 ms**（≥T5），随后开始 I²C。
  （RTL 常量 `RESET_WAIT_CYCLES = 119048` ≈ 5 ms @ 23.809524 MHz，另有额外等待。）
- XSHUTDN 常态：外部信号控制，或 **10 K 上拉到 DOVDD**。
- SID 必须接地或接 DOVDD，**不得悬空**。

### EXTCLK（MCLK）参数（SC520DS 表 3-3）

| 项目 | 最小 | 典型 | 最大 | 单位 |
|---|---|---|---|---|
| EXTCLK 频率 | 6 | — | 40 | MHz |
| 高/低电平脉宽 | 5 | — | — | ns |
| 占空比 | 45 | 50 | 55 | % |

- 本项目 FPGA 经 **L3** 输出 **23.809524 MHz** 作 EXTCLK（PLL C1）。
  ⚠️ 模组原理图标注"主机须提供 27 M"，而厂商寄存器表/RTL 按 24 MHz 设计；**实测 23.81 MHz 可用**。

## 6. MIPI 数据接口

来源：SC520DS §1.6；本项目 D-PHY 配置。

- 支持 8/10-bit，1/2-lane；VC 默认 0。
- 数据类型（DT，SC520DS 表 1-7）：

| DT | 描述 |
|---|---|
| 0x00 | 帧起始短包（FS） |
| 0x01 | 帧结束短包（FE） |
| 0x02 | 行起始短包（LS） |
| 0x03 | 行结束短包（LE） |
| 0x2a | 8-bit 数据长包（RAW8） |
| **0x2b** | **10-bit 数据长包（RAW10）** ← 本项目 |

- MIPI 调整寄存器（SC520DS 表 1-8）：`0x3018`（lane 数 / bit 模式）、`0x3031`（raw8/raw10）、
  `0x3650`（LP 驱动 / lane0 相位）、`0x3652`（lane0/1 延时，40 ps/step）、`0x3654`（时钟延时/反向）。

## 7. 关键功能寄存器速查

来源：SC520DS §1–§2。仅列常用项；完整初始化见 §9 附录。

| 功能 | 寄存器 | 说明 |
|---|---|---|
| 软复位 | `0x0103[0]=1` | 复位持续 150 ns；写 XSHUTDN 低亦复位（此时 I²C 不可用） |
| 睡眠模式 | `0x0100[0]` | 1=disable（正常工作），0=sleep |
| 流开 | `0x0100` 写 1 | 本项目初始化表末条即 `{0x0100, 0x01}`（stream on） |
| Sensor ID 高/低 | `0x3107` / `0x3108` | 默认 ee / 4b |
| MIPI lane 数 / bit 模式 | `0x3018` | Bit[7:5] lane 数（1=2lane）；Bit[4:0] bit 模式 |
| MIPI raw 模式 | `0x3031` | 0x08=raw8，0x0a=raw10 |
| 输出窗口宽度 | `{0x3208,0x3209}` | 默认 0x0a28 |
| 输出窗口高度 | `{0x320a,0x320b}` | 默认 0x0798 |
| 列/行起始 | `{0x3210,0x3211}` / `{0x3212,0x3213}` | 默认 0x0008 |
| 帧长 VTS | `{0x320e[6:0],0x320f}` | 步长 2，最大 0x7ff0 |
| Slave 模式 | `0x3222[0]` | 1=slave，0=master（本项目写 0，自由运行） |
| 触发 pad 选择 | `0x3224[4]` | 1=FSYNC，0=EFSYNC |
| FSYNC 输出使能 | `0x300a[2]` | 1=output，0=input |
| RB rows | `{0x3230,0x3231}` | Slave 模式读前等待行数 |
| 曝光时间 | `{0x3e00[3:0],0x3e01,0x3e02[7:4]}` | 步长 1（1/2 行），最小 4 |
| 模拟增益 | `0x3e09` | 见 §8 增益表 |
| 数字增益 | `0x3e06` | — |
| 数字细调增益 | `0x3e07` | 精度 1/32 |
| Group hold | `0x3812` | 写 0x00 启动，写 0x30 释放（帧内生效，最多 10 个寄存器） |
| 镜像/倒置 | `0x3221` | Bit[2:1]=mirror，Bit[6:5]=flip |
| 测试图（灰度渐变） | `0x4501` / `0x3902` / `0x3e07` | Bit[3]@0x4501 使能 |
